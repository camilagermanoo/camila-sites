# Camila Germano | Criação de sites personalizados

Site de vendas dos sites personalizados que eu crio.

## Rodando localmente

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run check
```

Roda o formatador, a verificação de tipos, o lint e os testes.

## Publicação

Cada push na `main` publica o site no GitHub Pages pelo workflow `.github/workflows/deploy.yml`.
